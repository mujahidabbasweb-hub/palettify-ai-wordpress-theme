# Palettify.ai — AI-Powered WordPress Design System Generator

**Palettify.ai** ek advanced, lightweight WordPress theme hai jo website ke name, industry, mood/audience, aur tech stack ke mutabiq instant professional design systems (color palettes, typography pairings, live previews, aur CSS/Tailwind variables) generate karta hai using **Groq AI (Llama / GPT models)**[cite: 11].

---

## 🚀 Features

- **AI-Driven Generation:** Automatically generates 3 unique design directions tailored to your brand's niche and target region[cite: 11].
- **Smart Color Systems:** Fully calculated background, primary, heading, body, and button color combinations with strong WCAG AA contrast.
- **Google Fonts Pairing:** Intelligent font family suggestions directly pulled from Google Fonts[cite: 11].
- **Built-in AI Assistant Chatbot:** Floating interactive guide that explains color psychology, typography, and helps users navigate the generator[cite: 8].
- **Customizable Admin Settings:** Clean dashboard configuration panel to securely input and manage Groq API keys[cite: 10].
- **Modern Glassmorphic UI:** Built with Tailwind CSS and custom animations for an ultra-sleek user experience.

---

## 🛠️ Tech Stack

- **Platform:** WordPress (Custom Theme Architecture)
- **Backend:** PHP, WordPress AJAX API, MySQL
- **Frontend:** Tailwind CSS, JavaScript (ES6), HTML5
- **AI Engine:** Groq API SDK (`api.groq.com/openai/v1/chat/completions`)[cite: 10, 11]

---

## ⚙️ Installation & Setup

1. Download the latest release `.zip` file from the repository[cite: 11].
2. Navigate to your WordPress Admin Dashboard: **Appearance > Themes > Add New > Upload Theme**.
3. Upload `palettify-ai.zip` and click **Activate**.
4. Go to **Appearance > Palettify Settings**, enter your Groq API Key (`gsk_...`), and save settings[cite: 3, 10].
5. Visit your homepage or the generated **Palettify** page to start creating design systems instantly!
